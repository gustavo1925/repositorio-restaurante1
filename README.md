Como rodar o sistema

1. Instale o Node.js
2. Instale o TypeScript
3. Abra o terminal na pasta do projeto
4. Instale as dependencias:


npm install


5. Rode o sistema:


npx tsc
node ./dist/Restaurant.js


Pronto, o sistema vai executar no terminal
